# 취준나침반 최종 기획안 초안

## 1. 서비스 개요

### 서비스명 및 한 줄 소개

**취준나침반**은 채용공고 탐색부터 직무 적합도 분석과 부족 역량을 보완할 교육 추천까지 한 번에 제공하는 AI 취업 준비 서비스이다.

### 해결하려는 문제

취업 준비자는 채용공고, 자신의 역량, 교육과정을 각각 다른 서비스에서 확인해야 하며 어떤 공고에 지원할 수 있는지와 부족한 역량을 어떻게 보완할지 판단하기 어렵다. 취준나침반은 희망 직무·보유 역량·자격증·이수 교육을 채용공고와 비교하고, 부족 역량에 맞는 교육을 연결한다.

### 주요 사용자

희망 직무를 정하고 취업을 준비하는 취업준비생 및 신입 구직자

## 2. 핵심 기능 및 이용 흐름

| 구분 | 기능 | 상세 내용 |
|---|---|---|
| 필수 | 회원가입·로그인 | Supabase Auth 기반 이메일 인증 및 세션 관리 |
| 필수 | 프로필 관리 | 희망 직무, 보유 역량, 자격증, 이수 교육 등록·수정 |
| 필수 | 채용공고 검색 | 검색어·직무·지역·경력·고용형태·마감 여부로 검색 |
| 필수 | 관심목록 | 채용공고와 교육과정 저장 및 조회 |
| 필수 | 직무 적합도 분석 | 프로필과 공고를 비교해 적합도·충족 역량·부족 역량 제공 |
| 필수 | AI 교육 추천 | 선택한 공고 또는 부족 역량에 맞는 교육과정 추천 |
| 추가 | 챗봇 | 취업 준비 질문에 답변하고 관련 화면으로 이동 지원 |

### 이용 흐름

회원가입 및 로그인 → 프로필 등록 → 채용공고 검색·저장 → 공고 선택 및 적합도 분석 → 충족·부족 역량 확인 → AI 교육 추천 → 교육 관심목록 저장

## 4. AI 기술 및 데이터 활용 계획

### 4.1 JEV 활용 직무 적합도 계산 모듈

사용자의 희망 직무·보유 역량·자격증·이수 교육과 채용공고의 제목·직무 상세·주요 업무·자격요건·우대사항을 비교한다. 공고 텍스트를 형태소 분석해 기술명·제품명·프레임워크·직무명 중심의 후보를 추출하고, 프로필과 비교해 충족·부족 후보를 분류한다. 이후 AI가 실제 직무상 부족 역량인지 검증하고 JEV를 통해 0~4점의 적합도 점수를 계산한다.

```text
적합도(%) = 50 + (AI 점수(0~4) × 12.5)
```

적합도는 합격 확률이 아닌 공고와 프로필의 역량 키워드 기반 참고 지표이다. 분석 결과는 공고별로 브라우저 `localStorage`에 저장하며 최근 5개까지 유지한다.

### 4.2 Groq 기반 AI 교육 추천 모듈

고용24에서 수집·저장한 교육과정 후보를 먼저 교육 종료 여부, 예산, 수강 방식, 역량 관련성으로 필터링한 뒤 Groq API로 최종 추천을 생성한다.

- 입력: 선택 공고, 희망 직무, 보유 역량, 자격증, 이수 교육, 학습 목표, 예산, 수강 방식
- 출력: 역량 분석 요약, 부족 역량 또는 학습 목표, 최대 15개 교육, 추천 이유 및 관련 자격증 참고
- 원칙: 교육명·분야·태그로 확인할 수 없는 커리큘럼이나 취업 보장을 AI가 추측하지 않는다.

## 5. 구현 가능성 및 검증 계획

### 구현 현황

회원 인증, 프로필 관리, 채용공고 검색·저장, 교육 목록·저장, 직무 적합도 분석, 공고 기준 교육 추천, 부족 역량 기준 교육 추천 API와 화면이 구현되어 있다. 각 기능은 인증 여부와 데이터·API 키 누락 상황에 따라 오류 메시지를 반환한다.

### 예상 제약 사항

- JEV·Groq·고용24 API 키 및 외부 API 상태에 따라 AI 기능이 제한될 수 있다.
- 적합도는 참고 지표이며 실제 합격 가능성을 보장하지 않는다.
- 교육 데이터가 부족한 항목은 고용24 원문 확인이 필요하다.
- 프로필 정보가 없으면 교육 추천이 제한된다.

### 검증 계획

| 대상 | 확인 기준 |
|---|---|
| 인증·보안 | 이메일 인증, 로그인, 보호 API의 비로그인 차단, 사용자별 데이터 분리 |
| 채용공고 | 필터·정렬·페이지네이션·마감 제외·저장/해제 |
| 프로필 | 희망 직무·역량·자격증·이수 교육 등록 및 재조회 |
| 적합도 | 점수 범위, 등급, 충족·부족 역량, 공고별 결과 저장 |
| 교육 추천 | 예산·온라인 조건, 공고 관련성, 추천 개수·추천 이유 |
| 오류 처리 | API 키 누락, 데이터 없음, 외부 API 실패, 잘못된 요청 안내 |
