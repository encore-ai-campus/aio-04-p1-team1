# API 명세서

> 기준: `app.py`에 등록된 FastAPI 라우터와 각 핸들러의 실제 동작
>
> Swagger UI: `/docs` · OpenAPI JSON: `/openapi.json`

## 1. 구분 기준

- **API**: JSON을 반환하거나 상태 코드만 반환하며, 프런트엔드가 `fetch`로 호출하는 경로
- **페이지 라우팅**: HTML을 반환하거나 다른 페이지로 리다이렉트하는 경로
- `/api` 문자열이 포함되어 있어도 HTML을 반환하면 페이지 라우팅으로 분류한다.
- 인증이 필요한 API는 로그인 세션 쿠키가 필요하다. 별도 `Authorization` 헤더를 사용하지 않는다.

## 2. 실제 API 목록

### 2.1 회원 인증 (`/api/auth`)

| Method | Path | 인증 | 실제 동작 | 성공 응답 |
|---|---|---:|---|---|
| POST | `/api/auth/signup` | 아니오 | 회원가입 요청 및 인증 메일 발송 | `202` |
| POST | `/api/auth/signin` | 아니오 | 로그인 및 세션 쿠키 발급 | `200`, `User` |
| GET | `/api/auth/me` | 예 | 현재 로그인한 회원 조회 | `200`, `User` |
| PATCH | `/api/auth/me` | 예 | 표시 이름 수정 | `200`, `User` |
| POST | `/api/auth/signout` | 예 | 현재 세션 종료 | `204` |
| POST | `/api/auth/password` | 예 | 기존 비밀번호 확인 후 비밀번호 변경 | `200` |
| POST | `/api/auth/withdrawal` | 예 | 비밀번호 확인 후 회원 탈퇴 처리 | `200` |

### 2.2 채용공고 검색 (`/job_posts/api`)

| Method | Path | 인증 | 실제 동작 | 성공 응답 |
|---|---|---:|---|---|
| GET | `/job_posts/api/filters` | 예 | 저장된 채용공고 기준 필터 선택지 조회 | `200`, `FilterOptions` |
| GET | `/job_posts/api/jobs` | 예 | 필터·페이지별 채용공고와 저장 여부 조회 | `200`, `JobResults` |

주요 검색 파라미터는 Swagger의 `SearchFilters` 스키마를 기준으로 한다.

### 2.3 교육목록

| Method | Path | 인증 | 실제 동작 | 성공 응답 |
|---|---|---:|---|---|
| GET | `/training_posts?data=true` | 아니오 | 지정 기간의 교육목록을 JSON으로 조회. 기본 기간은 오늘 기준 과거 1년~미래 1년 | `200` 또는 `503`, JSON |

`data`가 없거나 `false`이면 같은 경로는 교육목록 HTML 페이지를 반환한다.

### 2.4 직무 적합도·공고 데이터 (`/jd_match`)

| Method | Path | 인증 | 실제 동작 | 성공 응답 |
|---|---|---:|---|---|
| GET | `/jd_match/profile` | 예 | 현재 회원 프로필 조회 | `200`, `Profile` 또는 `null` |
| GET | `/jd_match/saved-job-postings` | 예 | 현재 회원 저장 채용공고 조회 | `200`, `SavedJobPosting[]` |
| GET | `/jd_match/job-postings/{job_posting_id}` | 아니오 | 채용공고 상세 조회 | `200`, `JobPosting` |
| GET | `/jd_match/job-postings/{job_posting_id}/score` | 예 | 회원과 공고의 적합도 점수 계산 | `200`, JSON |
| GET | `/jd_match/my-data` | 예 | 현재 회원 ID 반환 | `200`, `{"user_id": "..."}` |

### 2.5 교육 추천 (`/training_match/api`)

| Method | Path | 인증 | 실제 동작 | 성공 응답 |
|---|---|---:|---|---|
| GET | `/training_match/api/context` | 예 | 추천용 공고 목록과 프로필 요약 조회 | `200`, JSON |
| POST | `/training_match/api/recommendations` | 예 | 선택 공고와 회원 조건으로 교육 추천 생성 | `200`, JSON |

추천 생성은 선택 공고, 프로필 조건, `GROQ_API_KEY`, 저장 교육자료가 필요하다. 조건·후보가 없으면 `422`, 자료 조회 실패는 `503`이다.

### 2.6 관심목록 (`/api/bookmarks`)

| Method | Path | 인증 | 실제 동작 | 성공 응답 |
|---|---|---:|---|---|
| POST | `/api/bookmarks` | 예 | 채용공고 또는 교육 저장 | `201`, `Bookmark` |
| GET | `/api/bookmarks` | 예 | 유형·검색어·페이지 조건으로 목록 조회 | `200`, `BookmarkList` |
| GET | `/api/bookmarks/{bookmark_id}` | 예 | 관심목록 상세 조회. ID는 `job:<UUID>` 또는 `course:<UUID>` | `200`, `Bookmark` |
| DELETE | `/api/bookmarks/{bookmark_id}` | 예 | 관심목록 삭제 | `204` |

## 4. Swagger와 실제 동작의 차이

- `include_in_schema=False`인 `/auth/confirmed`, `/training_posts/`, `/training_match/`도 실제로는 동작한다.
- `/training_posts?data=true`는 같은 URL이 쿼리 파라미터에 따라 JSON API로 동작하는 예외적인 구조다.
- `/job_posts/api/*`, `/training_match/api/*`는 모듈 경로 아래에 있지만 HTML이 아닌 JSON API다.
- 기존 문서의 공고 등록·삭제와 교육 등록 API는 현재 라우터에 구현되어 있지 않다. 현재 구현된 범위는 공고·교육 조회, 추천, 관심목록 저장/삭제다.
